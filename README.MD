# Система бронирования зарядных станций для электромобилей

## Назначение
Веб-сервис для поиска, проверки доступности и бронирования слотов на станциях зарядки электромобилей. Решает проблему длительного ожидания в очереди и помогает оптимизировать процесс зарядки авто.

## Целевая аудитория
Владельцы электромобилей, операторы электрозаправочных станций (ЭЗС) и корпоративные автопарки.

## Предметная область
Инфраструктура зарядных станций для электротранспорта: учет параметров станций (мощность, тип коннектора, статус доступности) и управление слотами бронирования.

## Основные сущности
* **Зарядная станция** (идентификатор, адрес, тип коннектора, мощность)
* **Пользователь / Водитель** (имя, номер авто, баланс счета)
* **Бронирование** (дата, время, статус оплаты, выбранная станция)

## Основные функции
1. **Проверка доступности станции** на выбранную дату и время.
2. **Расчет стоимости сессии зарядки** на основе мощности станции и длительности.
3. **Оформление бронирования** с проверкой достаточного баланса на счету пользователя.

## План развития
На следующих этапах планируется:
* Разработка веб-приложения на Django;
* Подключение базы данных (PostgreSQL) для хранения пользователей и станций;
* Реализация системы аутентификации и личных кабинетов;
* Разработка REST API для мобильного приложения;
* Контейнеризация приложения с помощью Docker;
* Настройка CI/CD.
